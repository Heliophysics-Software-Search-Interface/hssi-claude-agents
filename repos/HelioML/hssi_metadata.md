**Scope note — read the evidence accordingly.** HelioML is not an installable library with a public
API. It is a Jupyter Book: a curated collection of ten worked chapters (an introductory "About This
Book" chapter plus Chapters 1–9), each reproducing the results of one peer-reviewed heliophysics
paper using machine learning, plus per-chapter conda environment specifications that pin the exact
package versions each chapter runs against. Consequently:

- **Functionality, formats, data sources, instruments and observatories are evidenced by notebook
  code**, not by exported functions. What the notebooks actually download, read, compute and plot is
  the capability being described.
- **A name-drop in prose is not support.** Several missions and instruments are named in the chapter
  narratives or in the book's Table of Contents but have no data file or code path in the repository;
  those are documented as omissions below rather than recorded as associations.
- The repository contains **no CITATION.cff, no codemeta.json and no .zenodo.json**. The
  authoritative structured metadata for the software is therefore the Zenodo/DataCite record
  generated by the GitHub–Zenodo release integration, supplemented by the repository's own README,
  `book/_config.yml`, `book/FrontMatter/table_of_contents.md` and the chapter notebooks.
- Chapter folder numbers are offset from chapter titles by one (`book/01` is "About This Book",
  `book/02` is Chapter 1, … `book/10` is Chapter 9). Evidence citations below use folder paths.

**Evidence for each value**

- **Data Processing and Analysis** — parent of the leaves below.
- **: ML/AI** — the book's subject matter. Support-vector regression and validation curves
  (`book/01`), support-vector classification with stratified k-folds (`book/02`), Keras convolutional
  networks (`book/03`), a PyTorch 1×1 convolutional DEM network (`book/04`), SVM with Fisher-score
  feature selection (`book/05`), MiniBatch k-means (`book/06`), a PyTorch U-net (`book/07`), a
  TensorFlow/Keras bidirectional LSTM (`book/08`), linear regression plus a TensorFlow CNN
  (`book/09`), Bayesian Gaussian mixture, UMAP and HDBSCAN (`book/10`).
- **: Analysis** — derived physical quantities and scientific evaluation throughout, e.g.
  proton-specific entropy `Sp = Tp/sqrt(np)` and charge-state ratios computed from Ulysses/ACE
  composition data (`book/10`), granulation contrast `sigma_I/I` and radial power spectra
  (`book/03`), plasma beta and temperature-ratio discriminators (`book/08`).
- **: Processing** — pipeline transformations: infinity/NaN replacement and time-based interpolation,
  standardisation and class weighting (`book/08`); log10 and Z-transforms (`book/09`); NaN dropping
  and outlier thresholding (`book/05`); image resampling with `congrid` (`book/03`).
- **: Data Access and Retrieval** — user-facing retrieval code in six chapters: the CCMC DONKI flare
  web service and the JSOC `jsoc_info` HTTP API for HMI SHARP keyword series (`book/02`); figshare
  downloads of the scintillation machine-learning database (`book/05`); `wget` of model weights and
  far-side maps (`book/07`); Zenodo downloads of MMS training/validation data and
  `pymms.sdc.mrmms_sdc_api.mission_events` queries against the MMS Science Data Center (`book/08`);
  an OSF archive download (`book/09`); `heliopy.data.ulysses` / `heliopy.data.ace` retrieval and a
  GitHub-release CSV download (`book/10`).
- **: Time Series Analysis** — SVR fit to an SDO/EVE irradiance light curve with seconds-since-start
  conversion (`book/01`, `book/01/jpm_time_conversions.py`); LSTM sequences built from time-ordered
  MMS survey data broken into SITL review windows (`book/08`); lagged feature construction
  `shift(periods=…)`, rolling means and a Δt forecast shift (`book/09`); 2 h/3 h resampling of
  spacecraft time series (`book/10`).
- **: Image Processing** — deconvolution and super-resolution of HMI continuum images and
  magnetograms, including PSF convolution with `astropy.convolution.convolve_fft` and azimuthal
  power-spectrum analysis (`book/03`, `book/03/enhance.py`, `book/03/radialProfile.py`); pixel-wise
  DEM inversion of six AIA channels at 512×512 (`book/04`); U-net segmentation of far-side seismic
  maps with `photutils.detect_sources`/`detect_threshold` blob detection (`book/07`); IRIS slit-jaw
  image handling (`book/06`).
- **: Data Reduction** — averaging/downsampling (`resample('3H').mean()`, `resample('2H').mean()`,
  `book/10`), univariate ANOVA feature selection reducing the input feature set (`book/05`), k-means
  centroid representation described in the chapter as giving "a coarse representation of the original
  unwieldily space" (`book/06`), and UMAP dimension reduction from six dimensions to two (`book/10`).
- **: Energy Spectra** — energy-resolved particle data are the analysis substrate in two chapters:
  the LSTM's feature set includes 31 `mms1_des_energyspectr_omni_fast_*` and
  `mms1_dis_energyspectr_omni_fast_*` omni-directional energy-spectrum channels (`book/08`), and
  Chapter 8 relates >100 keV, >300 keV and >1000 keV POES electron channels to 1 MeV fluxes across
  the spectrum (`book/09`). Recorded as analysis of energy-resolved fluxes; the book does not itself
  compute spectra from raw counts.
- **Data Visualization** — parent of the leaves below.
- **: Line Plots** — light curves with error bars (`book/01`), time-series and truth-vs-prediction

- **: 2D Graphics** — `imshow` of IRIS slit-jaw images and Mg II rasters (`book/06`), HMI/AIA and

- **: ML/AI** — validation curves (`book/01`), Fisher-score and feature-distribution plots and

- **: Instrument Response** — Chapter 2 forward-models the HMI instrument: it implements the Wachter

  Chapter 4 explicitly drops from its feature matrix (`book/05`). Consuming pre-transformed data is
  not a transform capability.
- `Mission-related` and all its subcategories — HelioML reads mission data but is not part of any

Five of these are broad domain-level regions — `Earth Atmosphere`, `Earth Magnetosphere`,
`Interplanetary Space`, `Planetary Magnetospheres`, `Solar Environment` — and each remains correct.
The other ten are the finer-grained regions the book's chapters actually treat, listed individually
because the available regions support that granularity and the evidence below supports each one.

- **Photosphere** — HMI continuum intensity and line-of-sight magnetograms of the solar surface
  (`book/03`); the 2832 Å IRIS slit-jaw band described in `book/06` as "scraping the upper
  photosphere".
- **Chromosphere** — the Mg II h & k resonance lines, whose "formation hight … extends over the
  entire chromosphere" (`book/06`).
- **Corona** — SDO/EVE 17.1 nm Fe IX emission from ~600,000 K coronal plasma (`book/01`); DEM
  inversion across logT 5.5–7.2 of the solar corona (`book/04`); coronal holes as the fast-wind
  source (`book/10`).
- **Solar Interior** — local helioseismology: far-side active-region detection from helioseismic
  holography of waves that propagate through the interior and refract back to the near side
  (`book/07`).
- **Solar Environment** — the broad solar-domain region covering Chapters 1, 2, 3, 5 and 6.
- **Solar Wind** — in-situ solar-wind composition and plasma from Ulysses and ACE (`book/10`);
  solar-wind Bz, dynamic pressure and Newell coupling function as scintillation predictors
  (`book/05`); solar-wind speed as a radiation-belt predictor (`book/09`).
- **Interplanetary Space** — Ulysses sampled 1.3–5 AU and out of the ecliptic, and the chapter
  analyses the radial distribution of its measurements (`book/10`).
- **Earth Ionosphere** — high-latitude ionospheric phase scintillation, TEC and spectral slope from
  GNSS receivers (`book/05`).
- **Earth Auroral Subregion** — the same chapter's high-latitude focus, with OVATION Prime diffuse,
  monoenergetic and broadband auroral electron fluxes and the AE electrojet index as features
  (`book/05`).
- **Earth Atmosphere** — the broad parent of the region actually treated; `Earth Ionosphere` is the
  specific one, and the broader value is kept because nothing shows it to be wrong.
- **Earth Magnetosphere** — Chapters 7 and 8 are magnetospheric.
- **Earth Outer Magnetosphere** — magnetopause crossings at the outer boundary (`book/08`).
- **Earth Magnetosheath** — a magnetopause crossing samples the magnetosheath on the outboard side,
  and the LSTM's discriminating features (`mms1_plasma_beta`, `mms1_temp_ratio`, ion and electron
  temperatures and densities) are exactly the sheath-versus-magnetosphere discriminators SITLs use
  (`book/08`).
- **Earth Inner Magnetosphere** — the outer radiation belt at L = 4.00–4.20 (`book/09`).
- **Planetary Magnetospheres** — no chapter treats a non-Earth magnetosphere; the support is the
  book's declared scope ("heliophysics … the study of the Sun and its effects on our solar system --
  the Earth, planets, minor objects", `book/FrontMatter/table_of_contents.md`). It is kept rather
  than removed because the absence of a planetary chapter is not evidence that the value is wrong.
  It is, however, the most weakly evidenced region in this list: its support is the book's declared
  scope, not the data or code of any chapter.

**Considered and not selected:** `Earth Thermosphere` (Chapter 4's scintillation is an F-region
ionospheric phenomenon; no thermospheric quantity is used), `Earth Magnetotail` (the MMS data used
are dayside — January 2017 SROI windows at the magnetopause), `Heliosheath`, and the individual
planetary magnetosphere regions (Jupiter, Mars, Saturn, Neptune, Uranus — no planetary data
anywhere).

### 22. Related Phenomena (OPTIONAL)

- Coronal Mass Ejections
- Geomagnetic Storms
- Solar Corona
- Solar Flares
- Solar Wind
- X-ray emission

Six values apply, each on the evidence below.

- **Coronal Mass Ejections** — Chapter 1 is titled "Predicting Coronal Mass Ejections" and classifies
  flaring active regions by whether they produced a CME (`book/02`); the introductory example fits a
  coronal dimming that "contains information about a violent coronal mass ejection" (`book/01`).
- **Solar Flares** — flare/CME association from M- and X-class events (`book/02`); Mg II spectra
  "during a solar flare" across many flaring active regions (`book/06`).
- **Solar Corona** — DEM inversion of the corona across logT 5.5–7.2 (`book/04`); Fe IX 17.1 nm
  coronal emission (`book/01`); coronal holes as the fast-wind source region (`book/10`).
- **Solar Wind** — solar-wind classification from composition and proton-specific entropy (`book/10`);
  solar-wind drivers in Chapters 4 and 8.
- **X-ray emission** — Chapter 1 selects events by GOES soft X-ray flare class and cross-checks them
  against the GOES X-ray flare event list; the Table of Contents records the data source as "Solar
  spectral irradiance > soft x-ray light … GOES/XRS flare event database" (`book/02`).
- **Geomagnetic Storms** — Chapter 4's features include the Kp, AE and SYM-H geomagnetic activity
  indices (`book/05`); Chapter 8 uses the Dst disturbance index and forecasts the storm-driven MeV
  electron enhancements that "pose a severe space weather threat" (`book/09`).

**Considered and not selected:** `Coronal Heating`. Chapter 3 constrains coronal temperatures
through DEM inversion, which is adjacent to heating studies, but neither the chapter nor its paper
claims coronal heating as a target, and selecting it would assert a science focus the book does not
have.

"part of the standard scientific Python ecosystem" would be no evidence at all.

Identity notes worth keeping, so they need not be rediscovered:

- SPASE describes two of these instruments twice, once in the Space Physics Archive Search and
  Extract working-group namespace (`SMWG/...`) and once in a mirrored CNES/AMDA namespace (ACE
  SWEPAM, Ulysses SWICS). The `SMWG/...` identifier is the canonical one and is what is recorded.
- Two entries share the name "Solar Wind Ion Composition Spectrometer" (ACE and Ulysses) and one
  shares its name with an observatory ("Interface Region Imaging Spectrograph"). That is correct:
  the identifier, not the name, is the distinguishing key.
- The names look inconsistent (`HMI`, `EVE`, `MMS FPI/DES`, `Solar Wind Plasma`) because each is the
  name SPASE gives that instrument rather than a normalised form. `Solar Wind Plasma` is what SPASE
  calls Ulysses SWOOPS.

**Instruments considered and deliberately not recorded:**

- **MMS EDP (Electric field Double Probe)** — the feature set includes `mms1_edp_x`, `mms1_edp_y`
  and `mms1_edp_z` (`book/08`), so the instrument is genuinely used, but SPASE holds no EDP record
  for MMS-1: it models the probes separately as `FIELDS/SDP` (spin-plane) and `FIELDS/ADP` (axial).
  Choosing between them, or asserting both, would be inference rather than evidence, so this
  association is carried at observatory level by the MMS-1 record in Field 32.
- **GOES XRS** — Chapter 1 uses the GOES X-ray flare event list throughout (`book/02`), but
  `sunpy.instr.goes.get_goes_event_list` queries a satellite-agnostic NOAA catalogue, and SPASE
  describes XRS only per spacecraft (GOES 5, 13, 14 and 15). Nothing in the repository selects among
  them, so the association is recorded at mission level in Field 32 instead of guessing a
  spacecraft.
- **POES MEPED** — the Chapter 8 input files are MEPED electron channels (`E2` >100 keV, `E3` >300
  keV, `P6` >1000 keV; `book/09`), but SPASE holds no POES instrument record at all — only the
  programme-level observatory. Recorded at observatory level in Field 32.
- **Van Allen Probes ECT (MagEIS/REPT)** — the chapter's 1 MeV electron target data are ECT-suite
  measurements, but the notebook names neither the instrument nor the probe, and SPASE holds
  separate `RBSP/A/ECT` and `RBSP/B/ECT` records. Recorded at mission level in Field 32.
- **SOHO/LASCO** (`SMWG/Instrument/SOHO/LASCO`) and **STEREO/SECCHI COR**
  (`NASA/Instrument/STEREO-{A,B}/SECCHI/Cor{1,2}`) — the Table of Contents lists "SOHO/LASCO and
  STEREO/SECCHI/COR coronal mass ejection database" as a Chapter 1 data source, which is why they
  were considered. The notebook reads neither: it queries the CCMC DONKI flare service and inspects
  each flare's `linkedEvents` for an associated CME identifier. DONKI is a derived, multi-instrument
  event catalogue, so the correct home for that dependency is Field 17, not an instrument
  association.
- **Hinode/SOT** (`SMWG/Instrument/Hinode/SOT`) — Chapter 2 validates `Enhance` against Hinode/SOT
  BFI continuum images and an SOT/SP Level 1D magnetogram, and describes the processing applied to
  them (`book/03`, the "In the wild" and plage-comparison sections). But no Hinode data file or code
  path exists in the repository — the chapter itself notes that large FITS materials were omitted,
  and the comparisons appear as pre-rendered figures (`docs/column34.png`,
  `docs/compararPlage.png`). The book does not read SOT data, so it is not designed to support it.
- **CHAIN GNSS receivers / GISTM** — Chapter 4's ionospheric inputs (phase scintillation index, S4,
  TEC, spectral slope) come from the Canadian High Arctic Ionospheric Network, and the database even
  carries `CHAIN station`, `CHAIN station model` and `CHAIN station ID number` columns (`book/05`).
  SPASE holds no CHAIN record and no GISTM record; the only ionospheric scintillation monitors it
  describes are Australian ASWS ground stations and DMSP SSI/ES sensors, none of which is the
  instrument used. Omitted rather than approximated, because no defensible record exists.
- **ACE MAG** — Chapter 9's prose says data are needed "some from SWICS, some from SWEPAM and some
  from the magnetometer", but the notebook fetches only `ace.swi_h3` and `ace.swe_h2`; no
  magnetometer product is retrieved. Excluded on the code evidence rather than the prose.
- **Wind, IMP 8 and Geotail** — listed in the Table of Contents as Chapter 4 solar-wind sources.
  Those are constituent spacecraft of the OMNI merged dataset the chapter actually uses; the merged
  product is recorded as `OMNIWeb` in Field 17.
